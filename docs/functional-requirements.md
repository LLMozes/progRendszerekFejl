# Funkcionalis kovetelmenyek

## 1. Auth es session
- Regisztracio: uj felhasznalo letrehozasa nev, email es jelszo megadasaval.
- Bejelentkezes: session alapjan azonositas email es jelszo hasznalataval.
- Kijelentkezes: session torlese a felhasznalo kijelentkeztetesehez.
- Session alapú hitelesites: minden vedett vegpont ellenorzi a bejelentkezest.

## 2. Szokasok kezelese
- Saját szokasok listazasa: a felhasznalo csak a sajat rekordjait latja.
- Szokas letrehozasa: cim, cel, gyakorisag es kategoria megadasa.
- Szokas szerkesztese: a sajat szokasok adatai frissithetoek.
- Szokas torlese: csak a sajat szokasok torolhetok.

## 3. Teljesitesek kezelese
- Teljesitesek rogzitese: datum/idopont, opcionális ertek es megjegyzes.
- Teljesitesek listazasa: csak a kivalasztott szokas sajat teljesitesei.
- Teljesitesek szerkesztese es torlese: csak a sajat szokashoz tartozo rekordok.

## 4. Dashboard statisztikak
- Osszes szokas szama.
- Osszes teljesites szama.
- Napi szokasok szama.
- Heti szokasok szama.

## 5. Admin funkciok
- Felhasznalok listazasa, szerepkor valtas (USER/ADMIN), torles.
- Kategoriak listazasa, letrehozasa, szerkesztese, torlese.
- Rendszerlogok megtekintese.
