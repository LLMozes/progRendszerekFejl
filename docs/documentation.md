# Projekt dokumentáció

## 1. Bevezetés

A projekt egy szokáskövető webalkalmazás, amelyben a felhasználók regisztráció és bejelentkezés után saját szokásokat hozhatnak létre, szerkeszthetnek, törölhetnek és teljesítéseket rögzíthetnek.

## 2. Választott technológiai stack

- Frontend: React + Vite + TypeScript
- Backend: Node.js + Express + TypeScript
- Adatbázis: SQLite
- ORM: Prisma
- Hitelesítés: express-session + bcrypt

## 3. Technológiai döntések indoklása

Az SQLite adatbázis választásának oka, hogy a projekt helyi fejlesztési környezetben egyszerűen futtatható, nem igényel külön adatbázis-szerver telepítést vagy felhős konfigurációt. A Prisma ORM segíti az adatmodell, a kapcsolatok, a migrációk és a demó adatok kezelését.

A React + Vite + TypeScript frontend gyors fejlesztést tesz lehetővé, jól használható VS Code környezetben, és alkalmas modern webes felület kialakítására.

A Node.js + Express + TypeScript backend egyszerűen alkalmas REST API végpontok kialakítására, amelyek a frontend és az adatbázis közötti kommunikációt biztosítják.
