# Nem-funkcionalis kovetelmenyek

- Egyszeru hasznalhatosag es attekintheto felulet.
- Frontend es backend szetvalasztasa onallo retegekre.
- REST API alapu kommunikacio.
- Session alapu hozzaferes-kezeles.
- Jelszavak hash-elese bcrypt segitsegevel.
- Karbantarthato TypeScript kod es kovetheto mappastruktura.
- Helyi fejlesztesi kornyezet tamogatasa (SQLite, Prisma migraciok).
- Demo adatok betoltese seed script segitsegevel.
